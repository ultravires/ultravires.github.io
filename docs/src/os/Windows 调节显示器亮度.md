一直很好奇为什么我的台式机接显示器无法通过滑块调节显示器亮度，甚至 Windows11 都没有调节亮度的入口。（PS：我的笔记本是有这个功能的）。

---

虽说显示的亮度调节可以通过显示器上的物理按钮进行操作，但操作起来多多少少有些繁琐。百度了一下，有人推荐 Windows 商店的 “Twinkle Tray” 应用。于是下载尝试了一下，果真可以，通过滑块调节显示器亮度方便多了。我也尝试观察通过应用滑块改变显示器亮度后再打开显示器上的物理按钮菜单，发现亮度是同步变化的，很 nice。
