安装适用于 Linux 的 Windows 子系统。

---

获取命令帮助

```sh
wsl.exe --help
```

安装适用于 Linux 的 Windows 子系统分发版

```sh
wsl.exe --install
```

查询有关有效分发版的列表

```sh
wsl.exe --list --online
```

安装 Windows 子系统分发版 Ubuntu-24.04

```sh
wsl.exe --install Ubuntu-24.04
```

设置镜像源 [清华大学开源软件镜像站_Ubuntu软件仓库](https://mirrors.tuna.tsinghua.edu.cn/help/ubuntu/)
