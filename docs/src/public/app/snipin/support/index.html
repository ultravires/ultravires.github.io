帮助 Snipin 正常工作的常见问题

快速上手

安装后，菜单栏会出现一个取景框图标。默认快捷键：区域截图 ⌥⇧A，窗口截图 ⌥⇧W。所有快捷键都可以在设置中重新录制。

首次截图前，请在「系统设置 › 隐私与安全性 › 屏幕录制与系统音频」中允许 Snipin 录制屏幕。授权后如果仍然无法截图，请退出并重新打开 Snipin，让系统权限生效。

常见问题

截图之后文件保存在哪里？

默认保存在你于设置中选择的文件夹，也可以在工具栏点按保存按钮另存。未保存的截图不会自行写入磁盘。

为什么快捷键没有反应？

系统级快捷键（例如 ⇧⌘4）会被 macOS 优先截获。请在设置中改用包含 ⌥ 或 ⌃ 的组合，并确认没有与其他 App 的热键冲突。

滚动截图为什么有拼接痕迹？

滚动截图依赖相邻两帧之间的重叠区域来对齐。单次滚动超过半屏高度时可能无法匹配，建议每次滚动幅度小一些。

如何申请退款？

所有付款均由 Apple 处理。请通过 reportaproblem.apple.com 向 Apple 提交退款申请。

Snipin 会上传我的截图吗？

不会。文字识别、滚动拼接与取色都在本机完成，App 不会发起网络请求。详见隐私政策。
