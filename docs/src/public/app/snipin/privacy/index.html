隐私政策

生效日期：2026 年 11 月 27 日

Snipin 是一款适用于 macOS 的截屏与标注工具。本页说明 Snipin 会如何处理它能够看到的内容，以及本网站记录哪些信息。

概要：Snipin 不收集、不存储、也不共享任何个人数据。

App 收集哪些数据

没有。Snipin 没有账号体系、没有统计分析、没有广告，也没有崩溃上报。App 自身不会发起任何网络请求，因此你截取的画面和标注不会离开你的 Mac。

屏幕内容

截图需要读取屏幕像素，因此 macOS 会在首次使用时请求“屏幕录制”权限。你可以随时在「系统设置 › 隐私与安全性 › 屏幕录制与系统音频」中撤回该权限。

  • 画面只在截图、滚动拼接、文字识别或取色时读取。
  • 处理全部在本机完成，不会上传到任何服务器。
  • 截图只会保存到你选择的文件夹，或在你主动复制时写入剪贴板。

快捷键与鼠标

全局快捷键通过 macOS 的 Carbon 热键接口注册，系统只会在你按下自定义组合键时通知 Snipin。App 不会读取你在其他 App 中输入的内容。

保存在你 Mac 上的内容

  • 你的偏好设置、快捷键与最近使用的选项。
  • 你主动保存的截图与钉图窗口状态（如适用）。

这些内容保存在本机。删除 App 及其数据即可清除。

购买与付款

Snipin 通过 App Store 以付费下载的方式销售。付款由 Apple 处理，开发者无法看到你的姓名、Apple 账户或支付信息。Apple 对数据的处理受 Apple 隐私政策约束。

本网站

本站不使用 Cookie、不做统计分析，也不加载第三方脚本。站点托管于 GitHub Pages，GitHub 可能为提供页面和处理安全请求而记录 IP 地址、浏览器类型等技术信息，详见 GitHub 隐私声明。

电子邮件

如果你写信寻求支持，我们只会使用你的邮箱地址和邮件内容来回复你。

儿童

Snipin 不向任何人收集数据，包括儿童。

政策变更

如果 App 将来以不同方式处理数据，本页会在相应版本发布前更新，并同步修改顶部的生效日期。
