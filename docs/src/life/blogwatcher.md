最近发现自己电脑终端里有很多实用工具，也不知道是什么时候装上的。今天又发现一个新的实用工具 `blogwatcher`，它可以订阅博客文章更新。

---

## 用法

`blogwatcher` 的用法也很简单

### 添加博客

```sh
blogwatcher add ultravires https://www.ultravires.me/
```

### 查看文章

```sh
blogwatcher articles
```
